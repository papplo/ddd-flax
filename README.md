# ddd-flax

Dokumentdriven analysplattform — MDX-dokument komponerar återanvändbara block (diagram, tabeller, insikter) som hämtar data live vid besök. Se [ARCHITECTURE.md](./ARCHITECTURE.md) för visionen och [REQUIREMENTS.md](./REQUIREMENTS.md) för kravbild och implementationsstatus.

Byggt med Vite + React Router (SPA-läge) + [Fumadocs](https://fumadocs.dev) + Tailwind CSS + shadcn/ui + [Bklit](https://bklit.com) charts.

## Utveckling

```bash
npm install
npm run dev
```

Öppnar på `http://localhost:5173`.

## Build

```bash
npm run build
```
